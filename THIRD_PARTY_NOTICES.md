# Third-party notices

## AI Job Search

This project adapts product-workflow ideas from [MadsLorentzen/ai-job-search](https://github.com/MadsLorentzen/ai-job-search), including the explicit job-fit, application tracking, interview preparation and outcome-feedback loop. It does not copy the repository's Claude Code runtime, portal scrapers, personal profile files, or third-party credentials.

## Interview Studio V3 libraries

- [Tesseract.js](https://github.com/naptha/tesseract.js) — browser OCR runtime, Apache-2.0.
- [PDF.js](https://github.com/mozilla/pdf.js) — scanned PDF page rendering, Apache-2.0.
- [three.js](https://github.com/mrdoob/three.js) — 3D mentor rendering, MIT.
- [word-extractor](https://github.com/morungos/node-word-extractor) — legacy DOC text extraction, MIT.
- [docx](https://github.com/dolanmiu/docx) — Word report generation, MIT.
- [jsPDF](https://github.com/parallax/jsPDF) — PDF report generation, MIT.

The application bundles the Tesseract Simplified Chinese and English trained
data from `@tesseract.js-data/chi_sim` and `@tesseract.js-data/eng`.
