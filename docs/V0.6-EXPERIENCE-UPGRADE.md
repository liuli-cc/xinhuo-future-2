# v0.6 整体体验升级记录

## 改了什么

- 虚拟导师：用原创半写实 2.5D 青年职业导师替换原 Three.js 程序化人物，五种面试状态通过光晕、信号条和文案给出可理解反馈。形象是 AI 生成的原创虚拟角色，不指向真实人物。
- 业务闭环：投递岗位可带入面试；面试复盘、岗位缺口、AI 建议和公开资源都可回到成长地图；成果仍须上传佐证并经教师审核。
- 导航与状态：新增学生端快捷导航，顶栏和侧栏统一使用数据库就绪探针，不再在未连后端时显示假的“已连接”。
- 响应式与动效：面试设置页在 390px 视口下不横向溢出，支持系统减少动效与用户手动选择。
- 性能：移除 `three` 和 `@types/three`，虚拟导师仅使用 Next Image 和 GSAP 的 transform/opacity 动效。

## 形象生成记录

- 模式：Codex 内置 ImageGen。
- 最终提示摘要：内蒙古师范大学职业导师场景中的原创半写实 3D 青年女导师，深钴蓝成长河背景，克制可信、非真人、无文字与 Logo。
- 最终资产：`frontend/public/liuli-mentor-v2.jpg`，1050×1400，仅用于本项目虚拟导师。

## 验收方法

```bash
cd frontend
npm ci
npm run lint
npm test
```

后端与数据库契约没有改动；仍应在 `backend/` 执行 `pytest`。本版未部署云服务，静态预览不代表线上环境。
