# 测试账号说明

> 本地开发环境的演示账号。所有人共用同一个本地库（MySQL `xinhuo`），所以大家看到的是同一批数据。
> 服务启动方式见 [README](../README.md)：后端 `uvicorn app.main:app --port 8000`，前端 `npm run dev`。

> ⚠️ **全新搭建的环境里没有这些演示账号**——账号存在数据库里、不随代码走。新环境请先执行
> `python scripts/bootstrap_admin.py` 创建管理员（详见 [数据导入教程](IMPORT-GUIDE.md) 第 1 步），
> 再按下方「注意」里的注册流程创建学生/教师演示账号。

## 常用体验路径

1. **学生视角**：登录 `20260801` → 实习就业 → 「岗位」开智能岗位推荐看匹配排序 → 「校招公告」按届数筛 → 「求职工作台」更新投递阶段、看时间线。
2. **教师视角**：登录 `20060801` → 教师工作台审核佐证；导入岗位/公告用管理接口（Swagger：`http://localhost:8000/docs` 搜 `import`）。
3. **权限验证**：学生调导入接口应返回 403（需就业管理授权）。

## 注意

- 测试密码仅限本地/演示环境，**严禁**在任何线上部署沿用。
- 新增演示账号请走注册接口（`POST /api/v1/auth/register`，学号须纯数字、密码 ≥10 位），注册后默认 pending，需教师或管理员激活。
- 授予/收回教师就业管理权限：管理员在「账号管理」中操作（`grant_employment` / `revoke_employment`）。
