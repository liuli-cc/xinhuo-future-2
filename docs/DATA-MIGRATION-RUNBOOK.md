# 旧数据迁移手册

1. 从旧系统导出 JSON，不直接让迁移脚本连接生产 CloudBase。
2. 保存不可变原始副本并计算 SHA-256；原始副本只读、限制访问。
3. 先运行 `python scripts/migrate_legacy_export.py export.json --dry-run`，修复所有错误。
4. 对目标 MySQL 做备份，再运行 `--apply`。脚本按学号、任务复合键和旧证据 ID 幂等写入。
5. 核对脚本输出的源记录数、写入数、跳过数与失败数；抽查账号、任务、佐证和审核关系。
6. 运行 `alembic current`、后端集成测试和前端验收；旧系统保持只读观察窗口。
7. 发现差异时恢复迁移前备份，不在部分失败的数据上重复手工修补。

真实旧数据与凭据不在仓库中，因此本版本只交付可审计迁移工具和演练流程，未执行生产迁移。
