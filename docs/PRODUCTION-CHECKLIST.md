# 上线前清单

- [ ] 学校确认运营主体、隐私联系人、服务协议和保存期限。
- [ ] 生产随机密钥、独立数据库账号、HTTPS、Secure Cookie 和精确 CORS 来源。
- [ ] `RETURN_SESSION_TOKEN=false`、受保护的 `METRICS_TOKEN`，并仅在可信反向代理后开启 `TRUST_PROXY_HEADERS=true`。
- [ ] COS 私有桶、服务端加密、生命周期和最小权限凭据。
- [ ] Redis/网关分布式限流、集中日志、指标、追踪和告警。
- [ ] 邮件/短信/校内通知与账号申诉渠道。
- [ ] 生产数据迁移演练、异地备份和恢复演练签字。
- [ ] 外部模型数据处理协议、费用上限、内容安全和故障降级。
- [ ] 压力、兼容、可访问性、渗透和依赖漏洞测试。
- [ ] GitHub 主分支保护、必需检查、评审人、发布回滚和紧急权限。
- [ ] 小范围试运行、用户支持和运营负责人排班。

以上涉及真实基础设施或学校审批，本次按要求未部署、未代填、未声称完成。
